# 隐私说明

## 数据处理

科研译镜不运营中转服务器。扩展只在用户主动点击翻译或测试接口时，把待翻译文字直接发送到用户在设置页填写的 API 地址。

- 网页翻译：发送扩展从当前页面识别出的可见文字。
- 网页划词翻译：只发送用户主动选中的文字。
- PDF 翻译：发送 PDF.js 从 PDF 文字层提取的文字；不向模型发送完整 PDF 文件。纯译文模式中的论文图片由浏览器在本机裁取，不会上传到翻译 API。
- 接口测试：发送设置页内置的一句英文测试文本。

用户应同时阅读所选 API 服务商的隐私政策和数据保留政策。

## 本地保存的数据

API 地址、各服务商分别保存的 API Key、模型名、目标语言、自定义 Prompt 和专业术语表保存在 `chrome.storage.local` 中。它们不会写入网页，也不会随本项目代码上传。切换服务商时只会使用当前所选服务商对应的密钥；Ollama 与 LM Studio 等本地模型请求不附带已保存的云端密钥。

PDF 的原文段落、已生成译文、黄色批注、阅读模式、缩放和滚动位置会按“稳定的正文内容指纹 + 翻译配置”保存在扩展自己的 IndexedDB 中，用于断点续译、段落匹配和恢复阅读位置。正文指纹是从 PDF 文字层在本机计算出的不可逆摘要，并会排除常见的动态下载水印；它不会上传到 API。此缓存不包含 API Key 或 PDF 二进制文件，默认 30 天自动清理，也可在阅读器中手动清除当前文献缓存。

用户可在设置页主动选择一个文件夹作为同步缓存目录。获得浏览器授权后，扩展会在该目录写入每篇文献独立的 `researchlens-session-*.json` 文件，其中包含上述原文段落、译文、批注和阅读位置，并在重新打开论文时参与恢复。浏览器内部 IndexedDB 始终保留为主缓存；停用自定义目录只停止后续同步，不会自动删除目录中已经生成的 JSON 文件。卸载扩展会清除浏览器扩展存储，但不会删除用户自行授权文件夹中的缓存副本。

在线 PDF 会由扩展后台使用浏览器现有的站点登录状态读取。扩展不申请 `cookies` 权限，也不会列出、查看或保存 Cookie。PDF 二进制数据只暂存在扩展自己的 IndexedDB 中，阅读器取走后会立即删除；只有提取出的文字在用户点击“翻译 PDF”后发送到所配置的 API。

当用户从出版商的增强型阅读器打开 PDF 时，扩展可能临时读取该页面的 HTML，用于查找其公开提供的 PDF 元数据或下载链接；HTML 不会发送给翻译 API，也不会持久化保存。扩展不会绕过付费墙、机构授权、人机验证或站点下载限制。

若出版商拒绝扩展后台跨站读取，扩展可能复用同域的已打开文章页，或临时创建一个非活动文章页，在该网站自身页面环境中读取用户已有权限访问的 PDF；读取结束后，临时页面会自动关闭。取得的 PDF 仍只进入扩展临时缓存，不会发送给翻译 API。

不要在共享电脑上保存私人 API Key。卸载扩展会清除其本地扩展存储。

## 浏览器权限

扩展使用 `<all_urls>` 主机权限，以便：

1. 读取用户主动要求翻译的网页文字；
2. 读取用户指定的在线 PDF；
3. 请求用户自行配置的任意兼容 API 地址。

扩展不会在后台自动抓取浏览历史，也不会自动上传页面内容。

## 敏感信息

用户不应翻译包含未公开研究数据、个人信息、商业秘密或受限制材料的页面，除非确认所选 API 服务商允许并妥善保护这些数据。
