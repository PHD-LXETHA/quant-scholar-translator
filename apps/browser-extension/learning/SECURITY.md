# Security

Please report suspected vulnerabilities privately to the repository owner
instead of opening a public issue. Include the affected version, reproduction
steps, and impact, but never include an API key, private transcript, or paid
paper.

The supported release line is the latest version on the default branch. Keep
Kimi credentials in Chrome local storage or environment variables, keep the
local backend bound to loopback, and review third-party model licenses before
redistribution.
