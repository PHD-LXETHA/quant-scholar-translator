# Contributing

Thanks for helping improve Quant Scholar Translator.

1. Open an issue describing the target webpage, video player, PDF source, or
   terminology domain. Never attach API keys, private transcripts, or paid
   papers.
2. Keep changes focused and preserve formulae, code, citations, timestamps,
   and glossary behavior.
3. Run the JavaScript and Python test commands listed in `README.md`.
4. Keep credentials in Chrome local storage or environment variables; do not
   add them to source, fixtures, screenshots, or logs.
5. Include licensing and source attribution for any newly adapted code, model,
   font, or dataset.

By submitting a contribution, you agree that your contribution may be
distributed under the repository's MIT license while third-party components
remain under their own licenses.
