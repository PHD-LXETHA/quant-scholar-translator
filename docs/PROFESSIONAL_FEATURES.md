# 专业翻译功能状态

标记：✅ 已纳入；◐ 已有基础、仍需增强；○ 尚未纳入。

## P0：首版必须

1. ✅ 原字幕优先，无字幕才启用 ASR，兼顾准确率与算力。
2. ◐ 专业领域自动识别和人工锁定已具备；章节级连续判断待增强。
3. ◐ 公式、代码、URL、引用和标识符保护已具备；单位与数字一致性校验待增强。
4. ◐ 领域术语与上下文提示已具备；翻译记忆和文档级一致性待增强。
5. ◐ 视频已保留原文、译文、来源 URL 和媒体时间戳；PDF 页码/边界框待接入。
6. ○ ASR、翻译和校验三类置信度分开呈现。
7. ○ 用户修正优先，并回流到项目术语库和翻译记忆。
8. ◐ Markdown、JSON、双语 SRT 与通用学习侧栏已具备；直接写入指定工作台 API 待接入。

## P1：专业增强

1. ◐ Whisper 分领域热词已接入；公司名、作者、希腊字母与公式口述二次纠错待增强。
2. 说话人区分；区分讲师、提问者和主持人。
3. 数字一致性校验：金额、百分比、日期、回归系数和显著性星号。
4. 术语解释卡：译法、英文定义、公式、出现位置和相关材料。
5. 自动章节、摘要、研究问题、方法、数据、结论与局限提取。
6. 跨视频、论文、网页与代码的语义检索和引用回答。
7. TBX 术语库与 TMX 翻译记忆导入导出。

## P2：高级能力

1. ◐ PDF 双栏/三栏、脚注、表格、图注与版式重建通过统一接口和可选 PDF 运行组件提供；扫描件已支持本地逐页 OCR、段落重建和浏览器批处理，复杂公式仍需对照原页复核。
2. 回归表结构化抽取，可导出 CSV/XLSX，并与原页截图对应。
3. LaTeX/MathML 公式识别与可搜索公式索引。
4. 实时配音，但默认低于双语字幕优先级。
5. 多模型复核：快速模型实时翻译，强模型异步校订知识库版本。
6. 本地向量索引、去重、版本更新和知识过期管理。

## 不建议首版加入

- 会员、账号和云端计费系统。
- 声音克隆和口型同步。
- 未经过验证的自动投资建议。
- 对 DRM 或付费墙的绕过。
