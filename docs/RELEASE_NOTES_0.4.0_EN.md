# Quant Scholar Translator 0.4.0

The first community-ready professional release, created and maintained by **LX.COCOSCENT / PHD-LXETHA**.

## Highlights

- Live bilingual captions for YouTube and general HTML5 video pages.
- Native captions first, with automatic local Whisper fallback and no audio upload.
- Terminology protection for finance, quantitative research, economics, statistics, mathematics, and programming.
- Kimi K3 professional translation, knowledge overviews, explanations, and note refinement.
- Local offline NLLB translation.
- A research PDF reader that protects formulas, code, citations, figure labels, and multi-column structure.
- Markdown, JSON, and bilingual SRT export for personal knowledge systems.
- No external transcript-service dependency.
- A unified professional navy, teal, and gold interface.

## Installation note

Load only `apps/browser-extension` from Chrome Developer mode. Run `scripts/setup.ps1` before first use. Model files and API keys are not included in the source archive.

## Privacy and licensing

Local Whisper does not upload audio. Text is sent to the configured Kimi endpoint only when a user explicitly invokes a Kimi-powered feature.
