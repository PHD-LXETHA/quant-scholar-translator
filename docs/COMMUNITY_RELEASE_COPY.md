# 社区发布文案 / Community Release Copy

## 中文版

我发布了 **Quant Scholar Translator 0.4.0**：一套面向技术视频、专业网页和科研 PDF 的本地优先双语学习工作台。

它会优先读取网页原字幕，没有字幕时使用本地 Whisper 实时识别；针对金融、量化、经济、统计、数学和编程内容保护术语、公式、代码与引用；还可以翻译科研 PDF，并把学习记录导出为 Markdown、JSON 或双语 SRT。音频在本地处理，只有主动使用 Kimi 功能时才会发送相关文本。

项目地址：https://github.com/PHD-LXETHA/quant-scholar-translator

欢迎试用、Star，也欢迎提交播放器适配、专业术语和翻译质量测试。

— LX.COCOSCENT / PHD-LXETHA

## English

I have released **Quant Scholar Translator 0.4.0**, a local-first bilingual learning workspace for technical videos, professional webpages, and research PDFs.

It prioritizes native webpage captions and falls back to local Whisper transcription when captions are unavailable. It protects terminology, formulas, code, and citations across finance, quantitative research, economics, statistics, mathematics, and programming. It also supports research-PDF translation and exports reusable learning records as Markdown, JSON, or bilingual SRT. Audio stays local; text is sent to Kimi only when a Kimi-powered feature is explicitly used.

Project: https://github.com/PHD-LXETHA/quant-scholar-translator

Stars, reproducible bug reports, player adapters, terminology contributions, and translation-quality tests are welcome.

— LX.COCOSCENT / PHD-LXETHA
