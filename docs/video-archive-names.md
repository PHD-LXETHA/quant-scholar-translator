# 视频存档名称

MD 文件名为 `00001 - 视频标题.md`，按首次存档顺序递增分配五位序号。按文件名升序排列即可查看存档顺序。标题中的 Windows 非法字符会被清理，超长标题会截短。

同一网站、视频编号和翻译设置使用固定序号、固定文件名；继续翻译只更新同一文档，网页标题变动也不重新编号。不同视频即使同名也不会共用编号。删除文件不会让其他视频重新排序或复用其序号。

`.data/catalog.json` 保存编号目录，其他 `.data/*.json` 保存真实视频身份和带时间戳的字幕。请连同整个 `.data` 文件夹一起备份，不要只保留 MD。回看按真实视频身份匹配，不依赖可见序号。

已有 `视频双语-短编号.md` 在迁移时仅改名，正文和时间戳恢复数据不变。遇到新旧文件冲突时不覆盖，请先人工核对。
