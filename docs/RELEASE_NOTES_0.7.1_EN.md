# Quant Scholar Translator 0.7.1

Created by **LX.COCOSCENT** (GitHub: **PHD-LXETHA**)

This is a compatibility hotfix for 0.7.0.

- Prevents non-standard synthetic `keyup` events without `event.key` from crashing the selection-translation content script.
- Keeps the floating launcher and complete menu responsive after such events.
- Makes the Codex persistent-home test portable when GitHub Actions on Ubuntu simulates a Windows `USERPROFILE`.
- Retains all 0.7.0 professional terminology, Codex/Kimi translation, CQF caption, bilingual video archive, and research-PDF features.

Chrome/Edge users should install `quant-scholar-browser-extension-0.7.1.zip`, or reload the updated source directory from the extensions page and then refresh open webpages.
