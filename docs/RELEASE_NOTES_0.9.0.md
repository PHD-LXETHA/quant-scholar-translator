# Quant Scholar Translator 0.9.0

本版本把 PDF 阅读器升级为 Quant Scholar 原创文档理解工作流。

- 自动识别学术论文、研究报告、报纸、杂志、图书与通用文档，也可手动纠正。
- 新增 1–4 栏阅读顺序与语义段落合并，改善三栏杂志、跨行正文和长篇材料的阅读版。
- Codex/Kimi 按完整语义段精译，阅读版展示完整段落，保版模式按原始坐标回填。
- 研报模式保留事实、分析、预测、投资建议、估值口径、风险和免责声明边界。
- 数学教材模式保护公式、变量、运算符、题号、例题与答案结构，只翻译自然语言说明。
- 缓存可恢复结构化段落、译文、文档类型、批注和阅读位置。
- 移除 BabelDOC 可选依赖、CLI 适配器与模型下载链路；文档理解不调用外部 PDF 重排项目。

升级后请在 Chrome/Edge 的扩展管理页重新加载 `apps/browser-extension`，并重新打开 PDF 阅读器标签页。
