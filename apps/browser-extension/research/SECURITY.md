# 安全政策

## 支持版本

安全修复仅面向最新 GitHub Release。请先确认问题在最新版本中仍然存在。

## 私下报告安全问题

请不要为 API Key 泄露、权限绕过、任意代码执行或敏感数据暴露创建公开 Issue。请使用 GitHub 仓库的 **Security → Report a vulnerability** 私下报告，并提供：

- 受影响版本与浏览器版本；
- 最小复现步骤和影响范围；
- 已脱敏的日志或截图；
- 建议的修复方向（如有）。

请勿在报告中附带真实 API Key、私人论文、机构访问凭证或未公开科研数据。维护者会先确认问题，再协调修复与披露时间。
