# Quant Scholar Translator 0.8.2

本版本重点改善扫描型 PDF 的专业翻译与导出体验。

- 自动识别无文字层页面，并明确显示 OCR、段落构建、精译和保存状态。
- 新增高密度行情页识别，保护数字表格、证券代码、公式和代码式区域。
- PDF 视图更名为“原版、保留版式、阅读重排、双栏对照”。
- 分别提供“导出保版 PDF”和“导出阅读版 PDF”。
- 任务面板增加运行时间、预计剩余时间和最近断点保存提示。
- Token 估算按实际批次命中的术语提示词计算，减少虚高估算。
- 跨页合批减少模型调用次数，同时保留逐页失败重试和断点恢复。

升级后请在 Chrome/Edge 的扩展管理页重新加载扩展，并重新打开已有的 PDF 阅读器标签页。
