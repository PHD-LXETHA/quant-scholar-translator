# Codex 专业翻译策略

- 固定模型：`gpt-5.6-sol`，首译推理强度 `medium`。
- 视频字幕和 `/translate` 的 Codex 纯文本段落翻译：首译同时返回疑难条目编号及原因码。术语义项、指代、推导关系或原文歧义尚未解决时，仅将对应条目交给同模型 `high` 再译一次。
- 复译提供原始段落、原文上下文、术语表，不提供首译结果。字幕编号、顺序和时间轴仍由程序负责。
- 首译 JSON、字幕编号或受保护内容校验失败时，该批无法安全定位译文，整批最多高等重试一次。高等结果仍未通过校验或报告实质歧义，则返回失败供用户核对，不无限升级或自动换模型。
- 登录、网络、额度等服务错误不会仅因该策略而触发高等调用。外层现有任务重试仍可能重试一个失败请求。
- Kimi、NLLB 路由不变，不与 Sol 混译。通用 `/codex/v1/chat/completions`（包含当前网页/PDF 自定义消息协议）固定中等，但不会擅自修改任意消息的输出格式；该通用通道尚未接入逐段疑难自动复译。
- 模型自报疑难不是准确率保证，不能发现所有错译，也不能补回缺失字幕或提取错误的公式。已有译文不会因模型配置改变自动重译。
- `/codex/status` 返回配置的模型、默认强度、复译强度；服务日志只记录请求模型、强度、条目数量与耗时，不记录课程正文。这些字段表示请求配置，不是服务端底层模型快照的证明。
- 代码修改后需要重启本地服务才生效。不要为切换配置中断正在运行的翻译或删除断点。

参数依据：[OpenAI 模型说明](https://developers.openai.com/api/docs/models/gpt-5.6-sol)。
