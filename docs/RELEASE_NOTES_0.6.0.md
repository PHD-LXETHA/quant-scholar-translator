# Quant Scholar Translator 0.6.0

作者：**LX.COCOSCENT**（GitHub：**PHD-LXETHA**）

## 专业实时翻译

- 新增“专业实时”“极速预览”“离线模式”三套工作流，默认使用专业实时。
- 专业实时先显示原文，再由 Codex/Kimi 直接依据原文、前文与领域术语库生成中文终稿。
- 极速预览将 NLLB 结果严格限定为临时 UI；Codex/Kimi 不读取 NLLB 译文，知识库也不保存临时译文。
- 音频识别与专业翻译异步运行，慢速模型调用不再阻塞后续音频采集。
- 最终译文新增数值、百分比、基点、货币、公式、变量、代码、URL、引用与缩写保护校验。

## 网页内完整悬浮菜单

- 移除 Chrome 锚定弹窗。点击扩展 QS 图标会在当前网页唤出完整悬浮菜单。
- 悬浮菜单完整覆盖实时翻译、语言、字幕样式、模型、翻译模式、专业领域、网页/PDF、设置、学习工作台及全部导出功能。
- QS 悬浮按钮支持拖动、位置记忆、自动淡化和运行状态提示；无需固定到工具栏，从扩展菜单点击同样可用。
- 调整学习侧栏头部留白，避免图标、标签与分隔线拥挤。

## iPhone、iPad 与 Safari

- 新增 Safari Web Extension 源码：点击 Safari QS 图标打开网页内菜单，读取网页公开字幕轨。
- Safari 同样支持专业实时、极速预览和离线模式；悬浮按钮可拖动并记住位置。
- 新增 Safari/Chrome 通用移动知识工作台，通过带配对令牌的局域网服务完成文本精译与 Markdown/JSON 导出。
- 明确能力边界：iOS Chrome 不能安装桌面 Chrome 扩展；iOS 无字幕视频不能通用捕获其他标签页音频。

## 隐私与本地性能

- 浏览器音频按约 1 秒的内存块发送到本机 Whisper，不创建 WAV、MP3 或 WebM 录音文件。
- Codex/Kimi 只接收文字，不接收音频。
- 移动 API 对非本机请求强制校验配对令牌。
- 当前开发机实测：NLLB 冷启动约 6.6 秒，预热后含技术数值保护的 60–70 字符英文句平均约 0.15 秒；不同硬件会有差异。

## 安装说明

Chrome 现有用户在 `chrome://extensions` 对 Quant Scholar Translator 点击一次“重新加载”，然后刷新已打开的网页。Safari 源码仍需经过 Apple 的 Web Extension 打包/签名流程才能安装到 iPhone 或 iPad，尚未完成真机端到端验证，属于实验性适配。完整验证记录见 `docs/VERIFICATION_0.6.0.md`。
