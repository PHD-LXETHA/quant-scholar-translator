# Quant Scholar learning workspace

This directory contains the side-panel learning workspace used by the unified
`Quant Scholar Translator` extension. It is not a standalone Chrome extension.

Load only the parent `apps/browser-extension` directory in Chrome. Transcripts
come from captions captured by the unified extension or from the local Whisper
service. Optional summaries, explanations, and note polishing use the user's
official Codex or Kimi Code subscription login. A Kimi API key is optional and
used only when the separate advanced API mode is selected.

Project documentation, installation instructions, licenses, and attribution
are maintained in the repository root.
